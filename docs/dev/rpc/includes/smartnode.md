## smartnode
Set of commands to execute smartnode related actions.

Available commands:
  count        - Get information about number of smartnodes
  current      - DEPRECATED Print info on current smartnode winner to be paid the next block (calculated locally)
  outputs      - Print smartnode compatible outputs
  status       - Print smartnode status information
  list         - Print list of all known smartnodes (see smartnodelist for more info)
  payments     - Return information about smartnode payments in a mined block
  winner       - DEPRECATED Print info on next smartnode winner to vote for
  winners      - Print list of smartnode winners

### Arguments
| Position | Name | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | command | string | True |  | The command to execute |
