## gobject deserialize
Deserialize governance object from hex string to JSON.

### Arguments
| Position | Name | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | hex_data | string | True |  | Data in hex string form. |

### Examples
```bash
raptoreum-cli gobject deserialize "hex_data"
```
