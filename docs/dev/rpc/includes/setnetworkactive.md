## setnetworkactive
Disable/enable all p2p network activity.

### Arguments
| Position | Name | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | state | boolean | True |  | true to enable networking, false to disable |

### Result
```text
true|false    (boolean) The value that was passed in
```
