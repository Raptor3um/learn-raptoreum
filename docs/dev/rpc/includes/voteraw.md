## voteraw
Compile and relay a governance vote with provided external signature instead of signing vote internally.

### Arguments
| Position | Name | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | mn-collateral-tx-hash | string | True |  |  |
| 2 | mn-collateral-tx-index | numeric | True |  |  |
| 3 | governance-hash | string | True |  |  |
| 4 | vote-signal | string | True |  |  |
| 5 | vote-outcome | string | True |  | yes|no|abstain |
| 6 | time | numeric | True |  |  |
| 7 | vote-sig | string | True |  |  |
